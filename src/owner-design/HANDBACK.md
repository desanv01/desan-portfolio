## Mount and private preview

`DesignStudio` receives serializable `initial: { document, revision, recordId, liveRevision?, versionId?: number|null }` and `previewRoutes: {pageId,label,path}[]`. Backend `src/owner/contracts.ts` remains authoritative. Studio adapters preserve numeric exact version IDs, read every media/history page, use same-origin/no-store credentials, and condition saves/restores against the loaded revision.

Mount `DesignStudioPreviewProvider` only in the authenticated owner preview route. `useIsOwnerDesignPreview()` is true immediately; `useDesignStudioPreview()` is null until the parent sends a valid design. Receiver checks same origin, exact parent window and the closed DesignDocument schema. Main's DesignFrame must explicitly use document/theme/mode/states/reducedMotion plus `ownerPreview` and `previewStates` runtime options. Public rendering with no provider keeps the original behavior. Private media support permits only exact `/api/owner/media/:id` when ownerPreview is true; manifest version/hash/rights/WOFF2 checks remain.

Studio creates an authenticated receipt from the latest saved design version plus the current exact published content selections; with no publication, it explicitly uses an empty content selection. It never selects all latest content drafts. Parent messages alter local valid presentation only. New attached resources require Save draft and Refresh content selection before the receipt can provide their bytes. Width/height/zoom/fit controls change the actual iframe viewport. Forced CSS states are scoped to the selected node; they do not perform business actions. Receiver reports actual overflowing node IDs and failed loaded font families to the parent.
