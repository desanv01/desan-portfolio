# Content import, discovery and sharing

`npm run content:import -- --input PRIVATE_MANIFEST --report PRIVATE_REPORT` reviews an explicitly approved manifest. Add `--apply` to create its drafts atomically. The format is `desan-reviewed-content` with an approval receipt and ordered `{key, collection, data}` records. A `{$ref: key}` value references an earlier record. Stable source keys are create-only: repeat imports preserve existing records and subsequent owner edits. No import publishes automatically. Keep personal manifests and reports outside public Git; publish only an exact reviewed selection through the publication API/workspace.

The active immutable publication is the sole source for canonical metadata, Open Graph/Twitter cards, `/sitemap.xml`, `/feed.xml`, search and public pages. Withdrawn or hidden/unselected records do not enter discovery. Source provenance and private fields are excluded before the public projection. RSS escapes XML and omits dates when only a year/month is known. No synthetic day is inferred.

`PUBLIC_SITE_URL` supplies a canonical origin independently of request Host headers. Local evaluation is noindex by default. `PUBLIC_SITE_INDEXABLE=1` additionally requires a public HTTPS origin; owner/admin/search/private routes remain excluded. Configure and verify the final production origin during deployment. Generated 1200×630 social cards use only selected public titles/descriptions; an owner-selected eligible SEO image takes precedence in metadata.

Public profile links come from the owner's selected profile version. Project/article pages offer copy-link sharing; the LinkedIn share link appears only when a public HTTPS site address is configured. A user still reviews and submits their own post. There is no automated LinkedIn posting, connection sync, scraping job or LinkedIn script embedded in the site. Primary references: [LinkedIn link sharing](https://www.linkedin.com/help/linkedin/answer/a525301/sharing-articles-or-links), [LinkedIn sharing integration](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/plugins/share-plugin), and the installed Next.js metadata/ImageResponse guides.

Analytics is **off**. No analytics provider, collection endpoint, event beacon or tracking script is installed. A future provider choice requires a separate configuration and privacy review; nothing is provisioned or purchased for local evaluation.
