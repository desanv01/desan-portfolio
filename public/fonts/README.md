# Local font assets

Licensed upstream fonts selected for the approved first-version design. Fonts are served locally with swap fallbacks. Each family retains its accompanying SIL Open Font License notice; no operating-system installation is required.

Upstream sources: [Syne](https://gitlab.com/bonjour-monde/fonderie/syne-typeface), [Fraunces](https://github.com/undercasetype/Fraunces), [Source Sans](https://github.com/adobe-fonts/source-sans), [IBM Plex](https://github.com/IBM/plex).
